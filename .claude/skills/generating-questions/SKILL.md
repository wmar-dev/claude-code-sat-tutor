# generating-questions

Provide an article URL or paste a passage. If the student is working from the Article Reading Summaries doc, use the URL from that entry.

## Steps

**1. Fetch or read the passage.** If a URL is given, fetch it. Trim to a ~300-word excerpt most suitable for question writing (prefer a section with a clear argument or finding).

**2. Print the excerpt** so the student can reference it while answering.

**3. Generate 4–6 questions** covering at least three of these SAT R&W question types:

| Type | Domain | Example stem |
|------|--------|--------------|
| Main purpose | Information and Ideas | "What is the main purpose of the text?" |
| Supporting evidence | Information and Ideas | "Which finding most directly supports the claim that…?" |
| Inference | Information and Ideas | "Based on the text, what can be inferred about…?" |
| Word in context | Craft and Structure | "As used in paragraph X, '[word]' most nearly means…" |
| Author's technique | Craft and Structure | "What does the author use the example of ___ to accomplish?" |
| Transition | Expression of Ideas | "Which choice most logically completes the sentence?" |

Format each question exactly like the SAT: stem + four lettered answer choices (A–D), with one clearly correct answer.

**4. After all questions**, print answers with brief explanations:
- State the correct letter.
- Explain in one sentence why the other three choices fail (use process-of-elimination language: "too narrow," "contradicted by the text," "out of scope," etc.).
- Name the pattern: what should the student remember for this question type?

**5. Note the domains covered** so the student knows which SAT skills they just practiced.
