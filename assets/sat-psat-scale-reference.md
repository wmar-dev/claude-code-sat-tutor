# SAT Suite Vertical Scale Reference

College Board's PSAT 8/9, PSAT 10, PSAT/NMSQT, and SAT all report scores on the same underlying **vertical scale** — a given score represents the same skill level across all four tests. **No concordance/conversion table is needed** to compare scores across these tests directly; a point delta between, say, a PSAT 10 score and an SAT score is meaningful as-is.

> "If you get a 1200 on the PSAT, you would have likely gotten a 1200 on the SAT if you took it the same day." — College Board, Vertical Scaling

## Score ranges (ceilings) by test

| Test | Total range | Section range (R&W / Math) |
|------|------------|------------------------------|
| PSAT 8/9 | 240–1440 | 120–720 |
| PSAT 10 / PSAT NMSQT | 320–1520 | 160–760 |
| SAT | 400–1600 | 200–800 |

## Ceiling effect caveat

If a score is **at or very near a test's maximum** for that section (e.g., PSAT 10 Math = 760/760), the lower-ceiling test doesn't include the hardest content needed to distinguish skill near the top. Treat that score as "≥ [ceiling]" — the true SAT-equivalent skill could be higher than reported, up to the SAT's max for that section.
