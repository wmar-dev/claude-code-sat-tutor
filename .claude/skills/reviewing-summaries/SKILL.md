# reviewing-summaries

The student pastes their summary. The article URL or title is optional but recommended.

## Steps

**1. Fetch the article** (if URL provided) to check accuracy. If no URL, work from the summary alone.

**2. Score the summary on four SAT-relevant dimensions** (1–5 each):

| Dimension | Score | Notes |
|-----------|-------|-------|
| Main idea accuracy | /5 | Did they capture what the article is *really* about? |
| Evidence and detail | /5 | Do they include the key finding/event that supports the main point? |
| Author's purpose | /5 | Do they show *why* the author wrote this — to inform, argue, describe? |
| Conciseness | /5 | Is every sentence doing work, or is there filler? |

**3. Specific praise** — quote one sentence from the summary that is strong and explain why it works.

**4. One revision target** — identify the single most important thing to improve. Quote the weak sentence, explain the problem, and rewrite it as an example.

**5. SAT connection** — name which R&W question type this summary skill directly trains:
- Capturing main idea → "What is the main purpose of the text?" (Information and Ideas)
- Tracking evidence → "Which finding best supports the claim?" (Information and Ideas)
- Identifying purpose → "What does the author use the example in paragraph 2 to do?" (Craft and Structure)
- Word precision → Words in Context questions (Craft and Structure)

Keep feedback direct and specific. Quote the student's own words. No vague praise.
